# 💰 Sistema de Gestão Financeira e Produtividade

> Um sistema web completo para administração de renda, organização financeira e agendamento de trabalhos, desenvolvido como meu primeiro projeto na área de tecnologia.

---

## 📋 Sobre o Projeto

Este projeto nasceu da necessidade de criar uma solução visual, intuitiva e prática para o controle financeiro pessoal e a gestão de compromissos profissionais. A aplicação foi estruturada para oferecer uma visão clara de entradas e saídas, previsibilidade de ganhos e automação no cadastro de despesas por meio de OCR.

---

## ✨ Principais Funcionalidades

* **🔐 Autenticação de Usuários:** Sistema de login seguro para acesso individualizado aos dados.
* **📊 Visão Financeira:** Painel completo para controle de entradas e saídas, permitindo acompanhar o fluxo financeiro em tempo real.
* **📅 Gestão de Eventos e Agendamentos:** Módulo dedicado ao registro de compromissos, valores a serem pagos e gráficos analíticos para previsibilidade financeira.
* **🧾 Leitura Inteligente (OCR):** Funcionalidade que permite ao usuário tirar uma foto de uma nota fiscal ou comprovante de pagamento para o preenchimento automático dos campos, necessitando apenas da confirmação dos dados.
* **🎨 Layout Modular:** Interface organizada em 3 layouts principais para separar o controle financeiro, a gestão de eventos e o registro de gastos de forma limpa e responsiva.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, JAVASCRIPT
* **Banco de Dados:** Neon (PostgreSQL) *(Iniciado com Google Sheets e migrado para maior robustez)*
* **Hospedagem & Deploy:** Vercel
